# Perfect Symmetry 派生・ステージゲーム仕様書

## 1. 目的と範囲

本書は、Perfect Symmetry の平面群パズルを、採点やランダム出題を省いたステージクリア型ゲームとして再構成するための仕様です。対象はゲームの仕様決定であり、本書自体は実装指示ではありません。

- 盤面は並進対称性を持つ格子であり、プレイヤーは図形を配置して指定の平面群を完成させる。
- ステージは 17 種の平面群を 1 回ずつ扱う固定順の全 17 ステージとする。
- 点数、ヒント、模範解答の手動表示、結果画面は設けない。完成時に即クリアとなる。
- UI は数字、アイコン、図形を主とし、平常時の説明文・装飾文字は置かない。平面群名はステージ選択と開発用データの識別子としてのみ扱い、プレイ画面には表示しない。

## 2. ステージ構成

ステージは最初からすべて選択可能で、以下の順序で並べる。これは平面群の操作が段階的に増えるようにした標準順である。

| No. | 平面群 | 格子 | 新たに使える操作 |
| ---: | --- | --- | --- |
| 1 | p1 | 直交 | なし |
| 2 | p2 | 直交 | 回転 |
| 3 | pm | 直交 | 反転 |
| 4 | pg | 直交 | なし |
| 5 | cm | 直交 | なし |
| 6 | p2mm | 直交 | なし |
| 7 | p2mg | 直交 | なし |
| 8 | pgg | 直交 | なし |
| 9 | c2mm | 直交 | なし |
| 10 | p4 | 直交 | なし |
| 11 | p4mm | 直交 | なし |
| 12 | p4mg | 直交 | なし |
| 13 | p3 | 六角 | なし |
| 14 | p3m1 | 六角 | なし |
| 15 | p31m | 六角 | なし |
| 16 | p6 | 六角 | なし |
| 17 | p6mm | 六角 | なし |

- 各ステージは常に対応する 1 種の平面群だけを出題する。ステージ番号と平面群の対応は変わらない。
- 図形種・色・大きさは、ステージを開始するたびにランダムに決める。図形種の候補は既存ハードモードと同じ 11 種とする。
- 図形サイズの基本範囲は、基本単位胞に対して 40〜50% とする。ステージごとのサイズ範囲はデバッグ専用画面で変更できるようにする。
- 山形の図形（`step_triangle`）は他の図形より輪郭が大きいため、描画時に縦横の比率を維持して公称サイズの80%とする。
- 直交格子の回転刻みは 90 度、六角格子の回転刻みは 60 度とする。
- 各ステージに表示する回転中心・鏡映軸・映進軸の組合せは固定する。初期版は各平面群で有効な組合せを暫定的に 1 つ選んで表示する。
- 後続のデバッグ専用画面では、ステージごとの対称記号セットを直感的に調整できるようにする。そこで確定したセットをコードへ貼り付けるためのデータ出力機能を持たせる。

## 3. 1 ステージの開始と初期配置

### 3.1 開始状態

- 未クリアのステージを開始したとき、またはリセット直後の盤面には、確定済みの図形を 1 個も置かない。クリア済みステージを選択した直後は例外として、最後に完成した模様を閲覧表示する。
- カーソルには、今回使用する図形を 1 個保持した状態で開始する。図形の初期角度と反転状態はランダムに決める。ただし角度は格子に応じた回転刻みのいずれかに限る。
- この未配置カーソルは、回転・反転できない。回転・反転ボタンも無効状態で表示する。
- 初期図形は、回転中心・鏡映軸・映進軸の上を含む任意の盤面位置に配置できる。特殊位置であることを理由に配置を拒否・補正しない。

### 3.2 最初の左クリック

- Canvas 上で最初に左クリックした位置に図形を配置し、これを初期図形とする。
- 初期図形の位置・角度・反転状態を基準に、そのステージの平面群から完成形（内部用の模範解答）を生成する。
- 模範解答は完成判定とスナップ判定のみに使用し、プレイヤーへは表示しない。
- 初期図形を配置した直後から、次の図形をカーソルに保持して通常の配置操作へ移る。この時点で、そのステージで許可された回転・反転ボタンを有効化する。
- p1 は並進対称性だけで完成するため、最初の左クリックによる初期図形の配置直後にクリアとする。

## 4. 操作とボタンの解放

| 操作 | 内容 | 利用条件 |
| --- | --- | --- |
| 左クリック | カーソルの図形を配置する | 常時。最初の 1 回は初期図形を置く |
| 回転 | カーソルの図形を格子の刻みだけ回す | ステージ 2 以降、かつ初期配置後 |
| 盤面上で右クリック | カーソルの図形を格子の刻みだけ回す。図形は配置しない | ステージ 2 以降、かつ初期配置後 |
| 反転 | カーソルの図形を左右反転する | ステージ 3 以降、かつ初期配置後 |
| 1つ戻る | 最後に追加した図形を取り消す | 初期配置後。初期図形は取り消せない |
| すべてリセット | 初期配置前の状態へ戻す | 常時 |
| 前へ／次へ | 前後のステージへ移動する | 常時。端では該当方向を無効化 |
| ステージ表示 | ステージ選択画面を開く | 常時 |

- 回転・反転はステージ進行で恒久的に解放されるのではなく、各ステージの開始時点で許可された操作だけを使える。したがって p1 は初期配置後も両方使えず、p2 は回転のみ、pm 以降は両方使える。
- 「1つ戻る」は、初期図形以後に置いた図形を新しい順に 1 個ずつ取り消せる。追加図形がないときは無効化する。
- 「すべてリセット」は、初期図形・追加図形・生成済み模範解答・操作履歴をすべて破棄する。押すたびに図形種・色・サイズ・角度・反転状態をランダムに再抽選し、未配置カーソルへ戻す。次の最初の左クリックで新しい模範解答を生成する。
- PC のクリック操作に対応する。タッチ操作は初期版の対象外とする。
- キーボードショートカットは、`N` で回転、`M` で反転、`B` で 1つ戻る、`R` ですべてリセットとする。

## 5. スナップと完成判定

### 5.1 スナップ

- スナップ機能は常にオンであり、設定でオフにはできない。
- 初期配置後、カーソル図形の回転角と反転状態が未配置の正解位置の状態と一致している場合、その位置の近傍へ近づけると正解位置に吸着する。
- 角度または反転状態が異なるときは吸着しない。
- 吸着半径は既存ゲームの配置アシストと同じく、基本単位胞の 7.5%（標準 200px 単位胞では 12px）とする。

### 5.2 完成

- 追加図形を置くたびに、初期図形を除くプレイヤー配置集合と、内部の正解配置集合を照合する。
- 位置、回転、反転がすべて一致する必要がある。格子の並進による同値位置は同一の配置として扱う。
- 必要な配置がすべてそろい、余分な配置がない時点で即座にクリアとする。採点ボタンや確定操作はない。
- 誤った配置はそのまま盤面に残る。プレイヤーは 1つ戻るまたはすべてリセットで修正する。
- 既存図形と位置・回転角・反転状態がすべて同じ位置をクリックした場合、配置処理を省略する。図形数、undo 履歴、完成判定は変化しない。位置が同じでも回転角または反転状態が異なれば別の配置として受け付ける。
- 初期図形を含む確定済み図形は、平面群にかかわらず 30 個を上限とする。重なって見える図形も、配置状態が異なれば個数に含める。
- 初期図形が特殊位置にあり対称変換後の図形が視覚的に完全に重なる場合も、必要配置数を減らさない。ただし、完全に同じ配置状態を重ねて要求する正解データは生成しない。プレイヤーは、位置が同じでも異なる回転・反転状態として必要な図形を置き続ける。
- 上限時は新しい図形を配置できない。クリックのたびに格子全体を別の色で 1 回点滅させ、配置できないことを示す。既存の配置やカーソル状態は変えない。

## 6. クリア演出と記録

- 完成直後に、短いステージクリア演出を再生する。演出中は盤面操作とステージ移動を受け付けない。
- 演出後、完成模様をステージ選択画面の該当ステージ枠へアルバムの作品のように収納するアニメーションを再生し、自動的にステージ選択画面へ移る。
- そのステージをクリア済みとして保存する。保存する内容は、平面群、初期図形を含む最終配置、図形種・色・大きさ、格子種、および完成時刻とする。
- クリア済みステージを再度選ぶと、最後に完成した模様を盤面に表示する。この閲覧状態で有効な編集操作は「すべてリセット」のみとする。
- 閲覧状態でリセットすると、初期配置前の新規プレイ状態へ移る。この時点ではクリア済み記録を削除せず、最後に完成した作品をバックアップとして保持する。
- リセット後に再度完成させた場合は、保存済み作品を最後に完成したものへ上書きする。完成せずに移動した場合は、途中経過を破棄してバックアップの作品を保持する。

## 7. ステージ移動と進行状態

### 7.1 通常画面の移動

- 前へ／次へを押すと、直ちに隣接ステージを開始する。ステージ 1 の前へ、ステージ 17 の次へは無効とする。
- 未クリアのステージから移動した場合、そのステージの初期図形、追加配置、模範解答、操作履歴は保存しない。戻ったときは未配置状態から新しく開始する。
- クリア済みステージをリセットして再プレイ中に移動した場合は、途中経過を破棄し、移動前の最後に完成した作品を保持する。
- ステージ移動に確認ダイアログは出さない。

### 7.2 ステージ選択画面

- 画面右上には現在のステージを `3/17` の形式で常時表示する。これを押すとステージ選択画面を開く。
- 選択画面には 17 個のステージ枠を番号順に表示する。すべての枠は最初から選択可能で、クリア条件によるロックはない。
- クリア済み枠には、そのステージで最後に完成した模様の縮小アイコンを表示する。未クリア枠には、対応するステージ番号（`1`〜`17`）を表示する。
- 枠を選択すると、そのアイコンが画面全体へ素早く広がる開始アニメーションの後、選択されたステージを表示する。現在プレイ中と同じステージを選んだ場合は、配置・カーソルの向き・模範解答・undo 履歴を保持して再開する。他ステージへ移る場合、未クリアの枠は新しい未配置状態で開始し、クリア済みの枠は最後に完成した模様の閲覧状態で開始する。移動元が未クリアなら、その進行は破棄する。
- 選択画面の `×` は選択画面だけを閉じ、盤面・カーソル・途中経過を変更せずゲームへ戻る。

## 8. 画面構成と視覚方針

### 共通デザイン原則

- 形は明瞭な輪郭、単色の上面で構成する。タイルには影や側面を付けない。ボタンの枠は角を 45 度に切り取った八角形とし、斜辺を含めて枠線の太さを一定にする。
- 色のグラデーション、ガラス風の透過パネル、ぼかし、強いドロップシャドウ、発光は使用しない。
- 各操作や情報を個別の枠・カード・パネルへ分割しない。格子 Canvas を中心とした一枚の盤面上に、操作アイコンと情報を直接配置する。
- ゲーム全体の背景の基調色は `#3c3e59`、ゲーム外の文字色は `#f0f2f5` とする。格子 Canvas の背景は `#f0f2f5`、Canvas 内の文字・記号色は `#3c3e59` とし、内外で色を反転させる。
- 図形タイルの基本パレットは、既存ゲームの `vintage` カラーセットを使う。ただし上記の背景色・文字色と競合する色は使わない。タイル地形画像（将来追加する場合）と UI 全体の色は同一色へ固定しない。

### デザイントークン

盤面背景、着地点の影、文字、ボタン上面、ボタン側面、選択、警告を役割別のカラートークンとして定義する。テーマ変更時も、役割間の明度差と文字の可読性を維持する。タイル色はこれらの UI 用トークンから独立して管理する。

| トークンの対象 | 役割 |
| --- | --- |
| 盤面背景 | Canvas 外側のゲーム背景 |
| Canvas 背景 | 格子を描画する領域の背景 |
| Canvas 文字・記号 | Canvas 内の文字、対称記号、線 |
| 着地点の影 | カーソル図形の着地点・配置状態を示す控えめな影 |
| ボタン上面／側面 | 単色上面と明暗を分けた側面 |
| 選択 | 現在のステージ、フォーカス、選択中の状態 |
| 警告 | 30 個上限時の格子点滅など、操作不能の通知 |

### 書体

| 用途 | 書体の性格 | 指定方針 |
| --- | --- | --- |
| タイトル、ステージ番号、短いボタンラベル | 繊細で幾何学的に整った書体 | 表示用書体トークンを設ける。数字には判別しやすい等幅数字を用い、桁数が変わっても位置を揺らさない。 |
| 説明文、設定名、ログ、確認文 | 可読性の高い標準的な日本語サンセリフ体 | 本文用書体トークンを表示用と分ける。長文には十分な行間を取り、英語表示でも改行とボタン幅が崩れないようにする。 |

通常プレイ画面では文章を極力表示しないが、設定、確認、将来のデバッグ画面には本文用書体を用いる。

### 画面全体の拡大縮小

- プレイ画面とステージ選択画面は共通の 1080 × 1080 のデザイン座標で配置する。盤面、操作ボタン、枠線、アイコン、数字、タイトルの相対位置と比率を固定する。
- 表示領域に収まる最大の共通倍率で画面全体を一括拡大縮小し、中央に置く。縦横比が変わった場合は外周の余白だけが変化する。

### プレイ画面

- 主要要素は格子 Canvas、カーソル図形、回転・反転・戻る・リセット・前後移動のアイコンボタン、右上のステージ表示だけとする。
- 六角格子のステージでは、水平方向と斜め 60 度・120 度方向の薄い補助線で三角格子を描く。中央の単位胞の輪郭は区別できる濃さで重ねる。
- 有効でない操作は隠さず無効状態で示し、機能が段階的に増えることを視覚的に伝える。
- 回転・反転・1つ戻る・すべてリセットのアイコンは、Perfect Symmetry の既存 SVG アセットを使用する。
- ボタンには文字ラベルを原則付けず、一般的に判別できるアイコンを使う。アクセシビリティ用の名称は DOM 属性として持たせる。

### ステージ選択画面

- 17 個の縮小枠、現在ステージの識別、閉じる `×` のみを基本要素とする。
- クリア済みの作品アイコンは、保存された最終配置だけを縮小描画する。アイコンの背景は盤面色とし、格子の補助線・単位胞の輪郭・対称記号は描かない。未クリアにはステージ番号だけを表示する。

### クリア演出

- テキストによる採点結果や模範解答は出さない。完成模様を保ったまま、簡潔な図形的アニメーションでクリアを示す。
- OS の `prefers-reduced-motion` が有効な場合は、演出を最小限の短いフェード等に置き換える。

## 9. 永続化

- 端末内の永続ストレージに、17 ステージそれぞれのクリア状態と最後に完成した作品データを保存する。
- 保存対象はクリア済み作品のみであり、未クリアの途中経過、未配置カーソルの乱数状態、undo 履歴、生成済み模範解答は保存しない。
- 保存データが欠損・不正な場合は、該当ステージを未クリアとして扱う。
- クリア記録をすべて消去する操作を用意する。実行前には確認を求め、実行後は全 17 ステージを未クリア状態に戻す。

## 10. 非対象

- スコア、採点内訳、ランキング、タイマー、ヒント、模範解答の閲覧、ギャラリー画面は本派生ゲームには含めない。
- 問題の重み付き抽選、問題セットのランダム選択、平面群の向き違いを別ステージにする仕組みは含めない。
- 設定画面でのスナップ切替は含めない。スナップは常時有効である。

## 11. 実装時の受け入れ条件

1. 起動直後にステージ 1（p1）が未配置カーソル状態で始まり、回転・反転は使えない。
2. ステージ 2 の初期配置後は回転だけが使え、ステージ 3 以降の初期配置後は回転と反転が使える。
3. 正しい状態のカーソルを正解位置近くへ置くと吸着し、状態が異なれば吸着しない。
4. 正解集合と完全一致した配置の直後に、採点操作なしでクリア演出と保存が行われる。
5. 未クリアの途中で別ステージへ移り、戻った場合は盤面が未配置に戻る。
6. クリア済みステージは、選択画面に最後の完成模様を表示する。未クリアはステージ番号を表示する。
7. どのステージも、クリア済みかどうかに関係なく選択画面から開始できる。
8. リセット後の最初の配置では、以前の模範解答を再利用せず新しく生成する。
9. p1 は最初の図形の配置直後にクリアとなる。
10. 30 個の確定済み図形がある状態では、31 個目を配置できない。
11. クリア済みステージをリセットして未完成のまま移動しても、直前に完成した作品アイコンが失われない。
12. 既存図形と完全に同じ配置をクリックしても、新しい図形は置かれず、配置数および undo 履歴は変わらない。
13. 特殊位置で重なって見える図形も、回転角または反転状態が異なれば別配置として完成判定に含める。
14. 30 個の上限でクリックしたとき、格子全体が 1 回点滅し、配置数とカーソル状態は変化しない。
15. 途中でステージ選択を開き、現在のステージを選び直した場合は初期化せず途中の盤面と操作状態へ戻る。
16. 回転可能なステージでは、初期配置後の右クリックでカーソル図形だけが回転し、配置数は増えない。

## 12. 開発者用ステージ設定画面

- ステージ選択画面の歯車から開く。プレイ用の設定と編集中の下書きは分離する。下書きは端末内に保存し、ゲームへ反映するには出力コードを `src/game/stages.js` の `STAGE_WORLDS` 宣言と置き換える。
- 設定データはワールド単位とし、各ワールドに17ステージを持つ。ワールドを追加すると `2-1`～`2-17` のように連番で作成する。クリア記録は `ワールド番号-ステージ番号` をキーにして、ワールド追加で既存記録の識別子が変わらないようにする。

## 27. ダブルモード・ブラインドモード

- 配置ゲージに誤配置を示す赤い区画が1つでもある間、使用可能な「一つ前に戻る」ボタンの縁をその面のクリア演出色にする。すべての区画が緑に戻ると通常色へ戻す。ステージ移動、リセット、取り消しでも現在の配置から再判定する。
- 第28節のデバッグ消去は「クリア判定のみ消去」に変更する。対象ステージの模様・図形・カーソル・途中経過は保持し、クリア済み判定、クリア後の追加記号、クリア日時だけを取り消す。他ステージのクリア記録は保持する。模様が完成済みなら再選択時に再クリア演出を行い、未完成ならその途中から続けられる。
- 対象の面が全クリアではなくなるため、その面から次の面へのボタンを隠す。その面の解放演出済み記録を取り消し、対象ステージを再クリアして面が再び全クリアになったときに演出を再実行する。後続の面のステージ進度は削除しない。最後の面なら最終面の全クリア演出済み記録を取り消す。

## 30. クリア演出中の入力

- 正解が確定してからステージ選択画面への収納と面解放演出が終わるまで、盤面配置、操作ボタン、ステージ移動・選択、面移動、開発者画面、進行データ消去の操作は受け付けない。
- 表示中のボタンはホバー・押下時の見た目の反応を維持し、クリックやショートカットによる状態変更だけを無視する。演出終了後に通常の操作可否へ戻す。

## 31. 全ステージクリア後の王冠

- 登録されている最後の面の全クリア演出が終わった後、アセット `assets/crown.svg` の王冠を上から落とし、ステージ選択画面のタイトル末尾の `a` の上に着地させる。着地時は小さく弾んで収まる演出とする。
- 王冠は最後の文字に相対配置し、画面全体の拡大縮小や書体差で位置が大きくずれないようにする。全ステージクリア後は面を移動してもタイトル上に表示し続ける。
- 全進行データ消去、または開発者画面でいずれかのステージのクリア判定を消去した場合、全ステージクリア状態でなくなるまで王冠を非表示にする。

## 32. 面クリア時のアイコン連鎖演出（改訂）

- 次の面の解放時と最終面の全クリア時は、ステージ1から17まで順にアイコンの縁をクリア色へ変える。序盤は軽快に進め、終盤ほど各アイコンの色が変わる間隔を少しずつ広げる。
- 最後の中央アイコンが変わる直前は、通常の終盤間隔より長い溜めを設ける。最後の色変化と同時に中央アイコンを少し跳ねさせ、着地してから次面ボタン、または王冠の演出へ進む。
- 16番目と最後の17番目のアイコンが色づく直前の間隔は、それぞれ800msと1000msとする。
- 1～13番目は通常約90msの間隔で色づけ、5→6と9→10の間隔だけ約140msにする。14番目以降からさらに間隔を広げる。中央の17番目は色変化と同時に跳ね始め、上昇に約660msを使ってゆっくり持ち上がってから着地する。
- 16番目の直前は800ms、17番目の直前は1000msとし、14・15番目をその間へ段階的に遅くする。色が変わる瞬間にすべてのアイコンを小さく跳ねさせる。1～16番目はホバーから通常位置へ戻るのに近い約440msの軽い上下動、最後の中央アイコンは従来のゆっくりした上昇を維持する。

## 33. クリア時の盤面外枠（改訂）

- 格子と図形のウェーブ後、盤面の外枠は左上から右下へ斜めに進む帯に沿って、面のクリア演出色へ変わる。4辺の同時変色は行わない。
- 色の移動は約400msで完了し、完成した枠を約360ms見せてから対称記号またはステージ選択への演出を続ける。動きを減らす設定では移動を省き、枠色を即時変更する。

## 34. 効果音

- 通常のボタン操作・ステージや面の選択には `sounds/switch6.mp3` を使用する。クリックのほか、対応するキーボード操作と右クリック回転も同じ音にする。無効な操作やクリア演出中の入力には鳴らさない。
- 格子への図形の確定配置には `sounds/put5.mp3` を使用する。重複配置や上限によって配置されなかった場合は鳴らさない。
- 全ステージクリア後の王冠が着地して跳ねる瞬間には `sounds/crown.mp3` を一度再生する。
- 開発者用画面の操作には効果音を付けない。再生失敗時もゲーム進行を妨げない。
- 配置上限で新たな図形を置こうとした際は `sounds/error.mp3` を鳴らす。
- ステージクリア時に盤面の縁がクリア色へ変わり始めるときは `sounds/clear.mp3` を鳴らす。
- ステージ選択画面でアイコンが一斉に上から現れる演出には、`put5` から事前生成した `sounds/put5-arrivals.wav` を一度だけ、通常より小さな音量で鳴らす。音源内の短い時間差をアイコンの斜め方向の出現順に合わせる。動きを減らす設定では鳴らさない。
- プレイ画面からステージ選択画面へ戻る際、直前のステージアイコンが枠へ収まる瞬間には単発の配置音を鳴らさない。その後に出現する他のアイコンには前項の合成音源のみを使用する。
- 面クリア時の17アイコン連鎖には、`pon` を少しずつ高い音程にして事前に合成した `sounds/pon-unlock.wav` を演出開始時に一度だけ再生する。最初の16音は各アイコンが緑色に変わる時刻、最後の1音は中央アイコンが着地する時刻に合わせる。実行時にアイコンごとの音を重ねない。最終面の全クリア時も同じ合成音源を使い、その後に王冠の着地音 `sounds/crown.mp3` を鳴らす。動きを減らす設定では連鎖音を省く。
- 面の全クリア後、次の面へ進むボタンが着地するときは、中央アイコンの最後の `pon` と同じ音程にした `sounds/pon-next-world.wav` を別途鳴らす。
- クリア後に追加の対称記号が落ちてくる場合は、最後の記号が着地する瞬間に `sounds/put2.mp3` を一度だけ鳴らす。記号が複数でも音を重ねない。
- 面の全クリア演出では、最後の中央アイコンが跳ねて接地した瞬間から800ms後に、次の面へ進むボタンが落下して接地するようにする。単発の `pon` はボタンの接地に合わせて鳴らす。

## 35. 製品版の開発者画面入口とクレジット

- ステージ選択画面の開発者画面ボタンは表示しない。操作可能なステージ選択画面で、キーボードから `kaihatusha` を順番に入力した場合だけ開発者画面を開く。確認ダイアログや遷移演出中は受け付けない。閉じた後はステージ選択画面へフォーカスを戻す。
- ステージ選択画面の進行データ消去ボタンには `assets/reset-btn.svg` を使用し、少し上へ移動した位置の下に小さく `Developed by Fermii` と表示する。
- 進行データ消去の確認メッセージ、確認ボタン、ゲーム画面のボタンのホバー文言は英語とする。

## 36. スマートフォン表示・操作

- タッチ主体・ホバーなし・画面幅950 CSS px以下の環境だけ、縦長の1080×1920基準レイアウトへ自動で切り替える。PCのウィンドウを縦長にしただけでは従来の正方形レイアウトを維持する。確認表示や切替ボタンは設けない。
- スマートフォンでは格子を上寄りに置き、ゲージ・ステージ表示・前後のステージ移動・操作ボタンを参考画像の位置と大きさに合わせる。格子とステージアイコン間の遷移は実際の枠矩形を使い、位置とサイズの飛びを作らない。
- 格子の下にタッチ操作エリアを設け、現在の図形をその向き・反転状態で表示する。ドラッグ中は操作エリア内の図形だけが指の移動に追従し、指を離したら中央へ戻す。円形アイコンはドラッグ中を含め通常は非表示とし、ステージ1の初回開始時だけ左右の矢印とともに直ちに表示する。未クリアの挑戦中（クリア済みステージをリセットして再挑戦中も含む）は約3.5秒操作がない場合にも円形アイコンと左右矢印を点滅表示する。矢印は円形アイコンと同じ上面色・濃い輪郭を持つ太い形とし、点滅で明るくなると同時に左右へ少し広がる。操作を再開すると非表示にする。格子内のカーソル図形の位置は指を離しても保持する。
- カーソル図形は操作エリアへの最初のタッチ時に盤面中央へ現れ、盤面外には移動しない。ステージ選択へ戻る、別ステージへ移る、またはクリアするまで表示する。ドラッグ中も他の指で回転・反転などのボタンを使える。
- 最初の図形（ダブルモードでは最初の2種類）はスナップ先がまだないため、指を離した位置に配置する。それ以降は正しい回転・反転で正解位置へスナップした時点で自動配置する。PCのクリック操作は変更しない。
- PC・スマートフォンとも、正しい図形を配置した直後はその図形を短時間クリア色で表示し、元の図形色へ滑らかに戻す。最後の正解配置でも色が戻ってからクリア演出へ進む。
- スマートフォンでステージ選択を表示している間は、正方形の選択画面の外側も含め、背後のゲーム画面を完全に隠す。

## 37. 操作配置・タッチ入力・描画負荷（改訂）

- プレイ画面上部の中央にステージ選択ボタンを置き、その左右に前・次のステージへ移動する三角ボタンを置く。PCとスマートフォンで同じ並びとし、スマートフォンでは盤面を少し広げる。盤面からステージアイコンへの拡大・縮小演出は、変更後の実際の枠矩形に合わせる。
- スマートフォンでは連続タップ・ピンチ操作によるページの拡大縮小と、ゲーム画面のスクロールを抑止する。操作エリアで図形をドラッグ中でも、別の指による回転・反転などの操作ボタンを受け付ける。各タッチ操作は一度だけ実行する。
- 進行データをすべて消去したらステージ選択画面を閉じ、未クリアのステージ `1-1` の初回問題を表示する。消去前に開いていたステージの状態を再保存しない。
- 格子と固定対称記号はステージごとに再利用し、確定配置済みの盤面は変化がある時だけ描き直す。マウス・タッチによるカーソル移動の描画は画面更新ごとにまとめ、操作に影響しない装飾用の再描画を避ける。
